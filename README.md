# 🛍️ Diwali Sales Data Analysis — Exploratory Data Analysis

## 📌 Project Overview

This project performs an **Exploratory Data Analysis (EDA)** on Diwali sales data using Python to understand **customer purchasing behavior, sales patterns, and product performance**.

The project follows a practical Data Analyst workflow, starting from raw data inspection and cleaning and progressing to exploratory analysis and visualization.

---

## 🎯 Objectives

The main objectives of this project are to:

* Understand the structure and quality of the dataset
* Clean and preprocess the raw sales data
* Analyze customer demographics
* Identify purchasing patterns
* Analyze sales across different categories
* Understand state-wise and occupation-wise purchasing behavior
* Identify high-performing product categories
* Generate business-oriented insights from the data

---

## 📊 Analysis Performed

### 1. Data Understanding

* Dataset structure
* Number of rows and columns
* Data types
* Basic statistical information
* Initial data quality checks

### 2. Data Cleaning

* Handling missing values
* Removing unnecessary columns
* Checking duplicate records
* Correcting data types
* Preparing data for analysis

### 3. Customer Analysis

* Gender-wise purchasing behavior
* Age-group analysis
* Marital-status analysis
* Occupation-wise purchasing patterns

### 4. Geographic Analysis

* State-wise orders
* State-wise sales
* Identification of major contributing regions

### 5. Product Analysis

* Product category performance
* Product-wise purchasing behavior
* Identification of high-performing categories
* Analysis of orders and revenue

### 6. Data Visualization

Visualizations are created using **Matplotlib and Seaborn** to make patterns and relationships easier to understand.
